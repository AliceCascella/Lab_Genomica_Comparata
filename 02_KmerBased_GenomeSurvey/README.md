# K-mer-Based Genome Survey

This section describes the preliminary assessment of sequencing data from *Anopheles stephensi* (Anoste), including read quality control, trimming, and k-mer frequency analysis.

## Quality Control of Raw Reads

The quality of the raw paired-end sequencing reads was assessed using [FastQC](https://github.com/s-andrews/FastQC). This tool provides information about per-base sequence quality, GC content, sequence duplication levels, and potential adapter contamination.

The following command was used to analyze the two FASTQ files:

```bash
# [assembly]
fastqc SRR11672503_1.fastq.gz SRR11672503_2.fastq.gz
```

The FastQC reports are available in the following files:

- [SRR11672503_1_fastqc.html](SRR11672503_1_fastqc.html)
- [SRR11672503_2_fastqc.html](SRR11672503_2_fastqc.html)

These reports were used to evaluate the quality of the sequencing reads before trimming and subsequent k-mer analysis.

---

## Read Trimming

Read trimming was performed using [Trimmomatic](https://github.com/usadellab/Trimmomatic) to remove sequencing adapters, low-quality bases, and reads that did not meet the specified quality criteria.

The trimming procedure was applied to the raw paired-end FASTQ files before the k-mer frequency analysis.

```bash
# [assembly]
trimmomatic PE -threads 8 -phred33 \
  SRR11672503_1.fastq.gz SRR11672503_2.fastq.gz \
  SRR11672503_1_paired.fastq SRR11672503_1_unpaired.fastq \
  SRR11672503_2_paired.fastq SRR11672503_2_unpaired.fastq \
  ILLUMINACLIP:/opt/miniforge3/envs/assembly/share/trimmomatic-0.40-0/adapters/TruSeq3-PE.fa:2:30:10 \
  LEADING:3 TRAILING:3 SLIDINGWINDOW:4:15 MINLEN:36 \
  2> stats_trimmomatic.log
```

Trimmomatic produces four output files: two containing paired reads that passed the filtering criteria and two containing unpaired reads whose mates were discarded during trimming.

The main trimming parameters were:

- `ILLUMINACLIP`: Removes sequencing adapter sequences.
- `LEADING:3`: Removes low-quality bases from the beginning of each read.
- `TRAILING:3`: Removes low-quality bases from the end of each read.
- `SLIDINGWINDOW:4:15`: Performs quality trimming using a four-base sliding window with a minimum average Phred quality score of 15. 
- `MINLEN:36`: Discards reads shorter than 36 bases after trimming.

The trimming statistics are available in the [stats_trimmomatic.log](stats_trimmomatic.log) file.
Only the paired reads retained after trimming were used for the subsequent k-mer frequency analysis.

## K-mer Frequency Analysis

Following read trimming, the paired-end reads were analyzed using [KAT (K-mer Analysis Toolkit)](https://github.com/EarlhamInst/KAT) to investigate the k-mer frequency distribution and estimate genomic characteristics.

K-mer analysis provides information about sequencing coverage, genome complexity, repetitive sequences, and potential heterozygosity.

The analysis was performed using a k-mer size of 27 and eight threads:

```bash
# [kat]
kat hist -t 8 -m 27 -o Anoste SRR11672503_1_paired.fastq SRR11672503_2_paired.fastq
```

The prefix `Anoste` refers to *Anopheles stephensi*, the mosquito species selected for genome assembly and annotation.

The main output files are:

- [Anoste.hist](Anoste.hist): Histogram containing the observed k-mer frequency distribution.
- [Anoste.png](Anoste.png): Graphical representation of the k-mer frequency histogram.

The k-mer frequency distribution was subsequently used for genome characterization with GenomeScope.

## GenomeScope Analysis

The k-mer frequency histogram generated with KAT was used for further genome characterization using [GenomeScope 2.0](http://genomescope.org/genomescope2.0/).

GenomeScope estimates genomic characteristics from the k-mer frequency distribution, including genome size, heterozygosity, repetitive content, and sequencing coverage.

The `Anoste.hist` file was used as input for GenomeScope to model the k-mer frequency distribution of *Anopheles stephensi*.

The relevant files available in this directory are:

- [Anoste.hist](Anoste.hist): K-mer frequency histogram used as input for GenomeScope.
- [Anoste.png](Anoste.png): K-mer frequency plot generated by KAT.
- [Anoste.dist_analysis.json](Anoste.dist_analysis.json): Additional distribution analysis results stored in JSON format.

These analyses provide a preliminary characterization of the sequencing dataset before proceeding to genome assembly.
